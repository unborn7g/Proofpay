The protocol

Five steps. Zero trust.

ProofPay translates a natural-language work agreement into verifiable outcome criteria, then lets autonomous payment happen only when validated work satisfies the brief.

01

Brief

The client writes the job in plain English and sets acceptance criteria plus budget.

02

Escrow

USDC locks into an intelligent contract nobody controls — not even the client.

03

Work

A worker agent builds and submits evidence: live URL, GitHub repo, report or dataset.

04

Validation

GenLayer validators open the live site and judge every criterion. Majority = consensus.

05

Settlement

All pass → funds release autonomously. Any fail → revision requested, money stays locked.

Old escrow

Pays on submission

Checks “did a file arrive?” An empty page, a broken form, a missing feature — all get paid anyway, because the escrow can’t read, look, or judge.

ProofPay

Pays on satisfaction

Checks “does the outcome meet the agreement?” Validators inspect the delivered work against the brief. Submission ≠ satisfaction — and now the difference is enforceable.

    Why GenLayer

    Only GenLayer can judge the web.

    Deterministic chains verify transactions. They cannot open a website and decide whether it meets a brief. ProofPay is GenLayer-native by construction.

    Web-aware validators

    The chain reads the evidence

    Validators render the delivered site themselves with gl.nondet.web.render — reachability, DOM, layout, sections — as canonical on-chain evidence.

    LLM judgment, on-chain consensus

    Subjective → verifiable

    Each criterion is adjudicated with gl.nondet.exec_prompt, and the equivalence principle turns five AI opinions into one consensus verdict the chain accepts.

    Autonomous settlement

    No humans, no invoices

    Payment releases only when the consensus says the brief is met. Fail → revision, funds locked, structured feedback returned. Trust becomes code.
